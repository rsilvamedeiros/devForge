# BTG — Engenheiro de Software Frontend (Angular) | Digital Equities

## Área

Digital Equities desenvolve aplicações relacionadas à jornada de investimento em renda variável, conectando clientes, operadores, áreas internas e serviços de mercado.

## Requisitos da vaga

### Obrigatórios
- JavaScript / TypeScript
- HTML / CSS
- Angular moderno (2+)
- APIs REST
- Git
- lógica de programação
- boas práticas
- contratos front/back
- organização e arquitetura frontend

### Valorizados / diferenciais
- testes automatizados
- performance
- APIs complexas
- WebSockets / real time
- microsserviços
- AWS
- UX / acessibilidade
- mercado financeiro
- projetos pessoais
- IA aplicada ao desenvolvimento

## Informação direta sobre a etapa técnica

Foi informado que a etapa com o time pode envolver **live code ou perguntas técnicas**, além de **exercício prático ao vivo**.

Focos explicitamente citados:
- estruturas de dados;
- listas;
- arrays;
- arquitetura;
- filas;
- algoritmos/performance;
- linguagem orientada a objetos.

A linguagem pode ser escolhida pelo candidato.

## Informação informal adicional

Outro desenvolvedor sugeriu atenção a:
- `map`;
- `filter`;
- `reduce`;
- operações de atualização em listas;
- consumo de lista do backend;
- transformação de dados;
- exibição;
- mudança de estado;
- responder conectando os conceitos ao Angular.

## Estratégia

Usar TypeScript no live coding e estudar cada fundamento em três níveis:

```text
TypeScript puro
   ↓
Angular
   ↓
Engenharia / performance / arquitetura
```
