# Metodologia de Estudo

## Ciclo de um tópico

1. Definição em linguagem simples.
2. Exemplo mínimo.
3. Implementação na mão.
4. Perguntas "por quê?" e "quando?".
5. Complexidade quando aplicável.
6. Exercício sem consulta.
7. Alteração de requisito.
8. Aplicação no framework.
9. Explicação oral em 30–60 segundos.
10. Registro de dificuldade.

## Regra para live coding

Antes de codar:
- confirme entrada/saída;
- pergunte restrições;
- identifique edge cases;
- descreva a solução simples.

Durante:
- pense em voz alta;
- use nomes claros;
- prefira solução correta antes de otimização;
- teste exemplos manualmente.

Depois:
- diga time complexity;
- diga space complexity;
- proponha melhoria;
- discuta trade-offs.

## Checklist de evidência

Uma skill só sobe de nível quando existe evidência:

- [ ] expliquei sem consultar;
- [ ] implementei sem consultar;
- [ ] resolvi exercício;
- [ ] expliquei Big O/trade-offs;
- [ ] apliquei em projeto;
- [ ] respondi em simulação/entrevista.
