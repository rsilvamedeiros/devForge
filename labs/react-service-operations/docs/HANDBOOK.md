# Handbook React

Referência do laboratório para dominar React moderno com TypeScript, do modelo de renderização à arquitetura de uma aplicação.

## Mapa

1. **Fundamentos e composição** — JSX, componentes, props, identidade e renderização.
2. **Estado, hooks e formulários** — ownership, reducer, effects, refs e entrada do usuário.
3. **Rotas e dados remotos** — Router, URL, fetch, cache, mutations e consistência.
4. **Arquitetura e experiência** — feature boundaries, acessibilidade, styling e design system.
5. **Qualidade e performance** — testes, profiling, memoização, concorrência e segurança.

## Competência esperada

- prever quando e por que um componente renderiza;
- modelar estado mínimo e derivar o restante;
- usar effects somente para sincronização externa;
- separar estado local, URL e servidor;
- implementar loading, error, empty, optimistic update e rollback;
- testar pelo comportamento percebido pelo usuário;
- medir performance antes de memoizar;
- explicar quando React puro não resolve SSR, routing ou data loading sozinho.

## Aplicação no lab

O Nexa Ops aplica composição, custom hooks, React Router, TanStack Query, mutation otimista, tema persistido, filtros e testes com Testing Library.
