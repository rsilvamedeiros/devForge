## Array
Boa iteração e acesso por índice. Busca por valor normalmente O(n).

## Map / Hash Map
Chave → valor. Lookup/inserção médios próximos de O(1). Útil para indexação e frequência.

## Set
Unicidade e membership médio O(1).

## Stack
LIFO: push/pop/peek.

## Queue
FIFO: enqueue/dequeue/peek.

## Linked List
Importante conceitualmente para entender nós e inserções; menor prioridade para esta entrevista.
